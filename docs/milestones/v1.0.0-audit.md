# PlanParity v1.0.0 completion audit

Audit date: 2026-08-23

## Phase 9 exit gate

All major CLI workflows are available through the embedded React interface and the same Go application services.

- State overview, modules, providers, outputs, resource search/filtering, dependency graph, and findings.
- Comparison counts, exact changes, before/after sanitized evidence, probable moves/signals, provider changes, impact graph, and findings.
- Plan, engine/provider upgrade, and Terraform/OpenTofu parity entry/results.
- Compatibility checks, known boundaries, schema differences, action details, JSON export, and process-memory-only history.
- Responsive desktop/mobile layouts, keyboard-visible controls, reduced-motion handling, text-only HTML rendering, and lazy Cytoscape loading.
- Real browser verification used synthetic raw state plus deterministic plan/parity fixtures. The release build produced no fresh browser warnings/errors and no seeded secret appeared in the DOM.

## Phase 10 exit gate

No known critical/high defect and no known path that mutates original state remains.

- `scripts/test.ps1` passed on Windows: formatting, vet, Go coverage suite, frontend dependency audit, lint, six UI tests, TypeScript, and production build.
- Linux x86-64 runner tests compiled; Linux x86-64 and ARM64 CLIs cross-compiled.
- Go's official `govulncheck` reported no vulnerabilities. `npm ci` reported 0 vulnerabilities.
- Windows Job Object and Unix process-group termination are covered by a process-tree timeout regression test.
- Spaces/long paths, regular-file limits, link escape, executable naming/link resolution, command argument isolation, bounded output, environment stripping, control-character removal, strict local API boundaries, secret canaries, HTML text rendering, and legacy null arrays are covered.
- Inspection and rehearsal verify original input hashes. Rehearsal executes only typed allowlisted engine operations inside copied workspaces.

Linux native race tests, file permission behavior, signal delivery, and shell scripts are repeated by the required GitHub Actions matrix before release.

## Phase 11 exit gate

- Documentation covers quick start, Windows/Linux installation, source builds, every workflow, local UI, safety, limitations, troubleshooting, architecture, and contributing.
- Four offline labs pass on Windows and are included in Windows/Linux CI:
  1. Basic value-free inspection.
  2. Module refactor with one inferred probable move.
  3. Candidate upgrade with one verified replacement and schema difference.
  4. Terraform/OpenTofu normalized plan mismatch.
- The labs use compiled deterministic protocol fixtures and require no cloud account, provider download, or network access.
- Tag pushes create Windows x86-64, Linux x86-64, and Linux ARM64 archives plus SHA-256 checksums, then publish a GitHub release.

## Release boundary

PlanParity is an analysis aid, not an operating-system sandbox or production guarantee. Provider code may still attempt local/network behavior. `FAILED`, `UNSUPPORTED`, `UNVERIFIED`, inferred, and ambiguous outcomes remain unresolved evidence.
