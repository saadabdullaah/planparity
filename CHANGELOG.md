# Changelog

PlanParity follows Semantic Versioning while public report and API contracts carry independent `planparity/v1` schema identifiers.

## v0.5.0-alpha.1 — Phase 8 foundation

- Established the Apache-2.0 local-first product and repository foundation.
- Added versioned, value-free state, plan, comparison, finding, provider-schema, inspection, and rehearsal models.
- Added Terraform and OpenTofu discovery, validation, version/capability detection, and normalized errors.
- Added state inspection, deterministic comparison, probable-move evidence, terminal output, and JSON reports.
- Added restricted copied-workspace plan, upgrade, and Terraform/OpenTofu migration rehearsals.
- Added localhost-only API v1, ephemeral session authentication, strict middleware, bounded jobs, SSE progress, cancellation, and in-memory exports.
- Added the embedded React UI with engine readiness, inspection, comparison and rehearsal entry points, sanitized state exploration, findings, and memory-only recent analyses.
- Added Windows/Linux CI, CodeQL, dependency review, Dependabot, contribution templates, and security-focused tests.

This is an alpha milestone. PlanParity is an analysis aid, not an operating-system sandbox and not a guarantee that an infrastructure change is safe.
