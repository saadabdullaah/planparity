# Changelog

PlanParity follows Semantic Versioning while public report and API contracts carry independent `planparity/v1` schema identifiers.

## v1.0.0 - Stable local compatibility laboratory

- Completed the responsive local workbench with state/module/provider exploration, resource search, dependency graphs, comparison dashboards, probable-move evidence, impact graphs, upgrade/parity screens, findings filters, and sanitized exports.
- Added value-free before/after resource evidence to the versioned comparison contract.
- Hardened copied workspaces with file size/count bounds, link rejection, original-input verification, reduced environments, bounded process output, and Windows Job Object or Unix process-group termination.
- Hardened terminal/browser boundaries against control, bidirectional, and HTML injection while preserving strict CSP and memory-only browser state.
- Added focused Windows/Linux path, executable, command-shape, timeout, process-tree, output-limit, secret-canary, server, and frontend regression coverage.
- Added complete user, workflow, UI, safety, limitation, troubleshooting, architecture, and contributor documentation.
- Added four deterministic offline labs that require no cloud account, provider download, or network access.
- Added reproducible Windows x86-64, Linux x86-64, and Linux ARM64 release archives with SHA-256 checksums and automated GitHub publication.

PlanParity remains an analysis aid, not an operating-system sandbox or a guarantee that a production change is safe.

## v0.9.0-beta.1 - Cross-platform hardening

- Added Windows/Linux and security hardening for the restricted runner, input boundaries, local server, reports, and embedded UI.

## v0.5.0 - Visualization and rehearsal UI

- Completed all major CLI workflows in the embedded React interface through the same Go application services.

## v0.5.0-alpha.1 — Phase 8 foundation

- Established the Apache-2.0 local-first product and repository foundation.
- Added versioned, value-free state, plan, comparison, finding, provider-schema, inspection, and rehearsal models.
- Added Terraform and OpenTofu discovery, validation, version/capability detection, and normalized errors.
- Added state inspection, deterministic comparison, probable-move evidence, terminal output, and JSON reports.
- Added restricted copied-workspace plan, upgrade, and Terraform/OpenTofu migration rehearsals.
- Added localhost-only API v1, ephemeral session authentication, strict middleware, bounded jobs, SSE progress, cancellation, and in-memory exports.
- Added the embedded React UI with engine readiness, inspection, comparison and rehearsal entry points, sanitized state exploration, findings, and memory-only recent analyses.
- Added Windows/Linux CI, CodeQL, dependency review, Dependabot, contribution templates, and security-focused tests.

This is an alpha milestone. PlanParity is an analysis aid, not an operating-system sandbox and not a guarantee that an infrastructure change is safe.
